# ADBuddy M2.5a · Clasificador con lista blanca y mksh real · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objetivo:** que el clasificador deje de depender de una lista de engaños conocidos. El evaluador de shell pasa a lista blanca (solo admite lo que lista y todo lo demás es 🔴 especial), y cada afirmación sobre mksh queda grabada contra el mksh real de un emulador de Android.

**Arquitectura:** sobre `m2` (4ffe9fc), solo en `host/internal/classify`, `scripts/` y `.github/`.
- **Corpus como datos** en `host/internal/classify/testdata/`: las órdenes habituales con su nivel (`habitual.jsonl`), el nivel que tenía en M2 cada línea 🟢 o 🟡 de los tests (`m2-levels.jsonl`) y las que suben, con su motivo (`raised.jsonl`).
- **Tests diferenciales:** cada caso lleva la centinela `@S@`, un programa que deja una marca al ejecutarse. `TestRecordOracle` ejecuta los casos en el mksh del emulador y graba el resultado en `oracle.jsonl`. El `go test` de siempre, sin emulador, exige 🔴 especial donde la centinela se ejecutó. Los casos de la lista blanca se generan.
- **Evaluador:** `classifyScript` deja de recorrer el árbol con `syntax.Walk` y pasa a una función recursiva con un caso por construcción admitida y 🔴 especial por defecto. Los envoltorios (`sh -c`, `find -exec`, `xargs`…), las reglas YAML, los checks y `special.go` no cambian de comportamiento.

**Tecnologías:** las de M2 (Go 1.27, `mvdan.cc/sh/v3` v3.14.1). Nada nuevo en `go.mod`. Emulador de Android (paquetes `emulator` y `system-images;android-37.0;google_apis;x86_64`, ya instalados en el PC del usuario) y bash para `scripts/emulator.sh`.

**Spec:** `docs/superpowers/specs/2026-09-30-adbuddy-m2.5-clasificador-lista-blanca-design.md` (§2.1, §3, §4, §5, §6, §8 y §9). La parte de la app (§7) es el plan M2.5b.

**Verificación del plan:**
- Todo el código sale de un prototipo que compila y pasa la suite completa del host (`go test ./...`, `go vet`, `gofmt`) en Windows 11 con Go 1.27.0.
- El oráculo se grabó contra el emulador (Android 17, SDK 37, `MIRBSD KSH R59 2020/10/31 Android`): 7923 casos, de los que 679 ejecutan la centinela; 72 builtins, palabras reservadas y alias. Dos grabaciones seguidas dieron el mismo fichero.
- **El emulador de Android 17 tiene un fallo gráfico:** `surfaceflinger` se cae cada pocos segundos y Android reinicia su sistema en bucle, lo que ralentiza todo. El grabador para el sistema Android (`su 0 stop`) mientras ejecuta los casos y lo vuelve a arrancar al terminar; así tarda unos 9 minutos y el oráculo sale idéntico al grabado con el sistema en marcha.
- El plan se reprodujo tarea a tarea desde su propio texto sobre `m2`: cada tarea compila y pasa sus tests por sí sola.
- **Huecos de M2 que encontró el oráculo** (60 casos en los que mksh ejecuta la centinela y M2 no da 🔴 especial). La tarea 2 los deja anotados (`knownM2Gaps`) y la tarea 4 los cierra:
  - `[ -v "$v" ]` y `[[ -v $v ]]` con `v='a[$(orden)]'`;
  - comillas dentro de `${x:-…}` entrecomillado: `echo "${x:-'$(orden)'}"`;
  - `sh -co nohup orden`, y envoltorios que dejan una opción como orden (`command -- orden`, `nice -n 1 -n 2 orden`).
- El plan pasó una revisión de `adbuddy-reviewer-opus` antes de ejecutarse; sus hallazgos están incorporados.
- **Si un paso no sale como dice el plan, detente y explícalo.**

package classify

// One-off: writes testdata/m2-levels.jsonl, the level at M2 of every shell
// line in the tests that is green or yellow. Run once on the M2 classifier,
// before the evaluator changes, and delete this file.

import (
	"bytes"
	"encoding/json"
	"go/ast"
	"go/parser"
	"go/token"
	"os"
	"path/filepath"
	"sort"
	"strconv"
	"strings"
	"testing"
)

func TestZZWriteM2Levels(t *testing.T) {
	c, err := New(nil)
	if err != nil {
		t.Fatal(err)
	}
	lines := map[string]bool{}
	files, _ := filepath.Glob("*_test.go")
	fset := token.NewFileSet()
	for _, f := range files {
		// Only the tests of M2: not this file, nor the corpus tests of M2.5.
		if strings.HasPrefix(f, "zz_") || f == "corpus_test.go" || f == "differential_test.go" {
			continue
		}
		af, err := parser.ParseFile(fset, f, nil, 0)
		if err != nil {
			t.Fatal(err)
		}
		ast.Inspect(af, func(n ast.Node) bool {
			switch n := n.(type) {
			case *ast.BasicLit:
				if n.Kind == token.STRING {
					if s, err := strconv.Unquote(n.Value); err == nil {
						lines[s] = true
					}
				}
			case *ast.CompositeLit:
				var parts []string
				for _, e := range n.Elts {
					bl, ok := e.(*ast.BasicLit)
					if !ok || bl.Kind != token.STRING {
						return true
					}
					s, _ := strconv.Unquote(bl.Value)
					parts = append(parts, s)
				}
				if len(parts) > 1 && parts[0] == "shell" {
					lines[strings.Join(parts[1:], " ")] = true
				}
			}
			return true
		})
	}
	type row struct {
		Sh    string `json:"sh"`
		Level string `json:"level"`
	}
	var rows []row
	for line := range lines {
		if strings.TrimSpace(line) == "" || strings.ContainsRune(line, 0) {
			continue
		}
		level, ok := func() (l Level, ok bool) {
			defer func() {
				if recover() != nil {
					ok = false
				}
			}()
			return c.Classify([]string{"shell", line}).Level, true
		}()
		if ok && level != Red {
			rows = append(rows, row{line, level.String()})
		}
	}
	sort.Slice(rows, func(i, j int) bool { return rows[i].Sh < rows[j].Sh })
	var b bytes.Buffer
	enc := json.NewEncoder(&b)
	enc.SetEscapeHTML(false)
	for _, r := range rows {
		if err := enc.Encode(r); err != nil {
			t.Fatal(err)
		}
	}
	if err := os.MkdirAll("testdata", 0o755); err != nil {
		t.Fatal(err)
	}
	if err := os.WriteFile(filepath.Join("testdata", "m2-levels.jsonl"), b.Bytes(), 0o644); err != nil {
		t.Fatal(err)
	}
	t.Logf("%d lines", len(rows))
}
````

//	mksh-builtins.tsv   the builtins, reserved words and aliases of that mksh

// corpusCase is one line of a corpus file. A shell line is {"sh": …}; any
// other adb command is {"argv": […]}.
type corpusCase struct {
	Sh      string   `json:"sh,omitempty"`
	Argv    []string `json:"argv,omitempty"`
	Level   string   `json:"level,omitempty"`
	Special bool     `json:"special,omitempty"`
	Why     string   `json:"why,omitempty"`
	Ran     bool     `json:"ran,omitempty"`
}

func (k corpusCase) argv() []string {
	if k.Argv != nil {
		return k.Argv
	}
	return []string{"shell", k.Sh}
}

func (k corpusCase) level(t *testing.T) Level {
	t.Helper()
	l, err := ParseLevel(k.Level)
	if err != nil {
		t.Fatalf("%q: %v", k.argv(), err)
	}
	return l
}

// readJSONL reads a corpus file; lines starting with # are comments.
func readJSONL[T any](t *testing.T, name string) []T {
	t.Helper()
	data, err := os.ReadFile(filepath.Join("testdata", name))
	if err != nil {
		t.Fatal(err)
	}
	var out []T
	sc := bufio.NewScanner(bytes.NewReader(data))
	sc.Buffer(make([]byte, 1<<20), 1<<20)
	for n := 1; sc.Scan(); n++ {
		line := strings.TrimSpace(sc.Text())
		if line == "" || strings.HasPrefix(line, "#") {
			continue
		}
		var v T
		dec := json.NewDecoder(strings.NewReader(line))
		dec.DisallowUnknownFields()
		if err := dec.Decode(&v); err != nil {
			t.Fatalf("%s:%d: %v", name, n, err)
		}
		out = append(out, v)
	}
	if err := sc.Err(); err != nil {
		t.Fatal(err)
	}
	return out
}

func loadCorpus(t *testing.T, name string) []corpusCase {
	t.Helper()
	return readJSONL[corpusCase](t, name)
}

			words := strings.Fields(argv[1])
			for i := 1; i < len(words); i++ {
				safeClassify(t, c, sh(strings.Join(words[:i], " ")))
			}
		}
	}
	if r, ok := safeClassify(t, c, sh("dumpsys")); ok && r.Level != Green {
		t.Errorf("dumpsys: %v (%s: %s), want green", r.Level, r.Primary.Rule, r.Primary.Reason)
	}
}

// safeClassify classifies a command and reports a panic as a test error.
func safeClassify(t *testing.T, c *Classifier, argv []string) (r Result, ok bool) {
	t.Helper()
	defer func() {
		if p := recover(); p != nil {
			t.Errorf("%q: panic: %v", argv, p)
			ok = false
		}
	}()
	return c.Classify(argv), true
}

// testNeighbours are the variables a static word next to the data names
// when mksh evaluates it as arithmetic (-n reads n): each holds the payload.
var testNeighbours = "n='a[$(@S@)]'; z=$n; f=$n; e=$n; r=$n; a=$n; o=$n; x=$n; y=$n; "

// generatedCases builds the cases the allowlist makes finite: every way to
// give a variable a payload, used in every admitted way and in the ways
// that are not admitted; and every admitted expression of test with each
// word of data being an operator or the payload.
func generatedCases() []string {
	seen := map[string]bool{}
	var out []string
	add := func(s string) {
		if !seen[s] {
			seen[s] = true
			out = append(out, s)
		}
	}
	names := make([]string, 0, len(payloads))
	for name := range payloads {
		names = append(names, name)
	}
	sort.Strings(names)
	for _, name := range names {
		for _, carrier := range carriers {
			for _, sinks := range [][]string{admittedSinks, otherSinks} {
				for _, sink := range sinks {
					add(fmt.Sprintf(carrier, payloads[name], sink))
				}
			}
		}
	}
	for _, text := range quotedTexts {
		for _, context := range textContexts {
			add(fmt.Sprintf(context, text))
		}
	}
	for _, line := range wrapperLines {
		add(line)
	}
	testCases := func(shape string, operands []string) {
		two := strings.Contains(shape, "%[2]s")
		for _, p := range operands {
			qs := []string{""}
			if two {
				qs = operands
			}
			for _, q := range qs {
				expr := strings.NewReplacer("%[1]s", "$p", "%[2]s", "$q").Replace(shape)
				set := fmt.Sprintf("p='%s'; q='%s'; ", p, q)
				add(set + expr)
				add(testNeighbours + set + expr)
			}
		}
	}
	for _, shape := range testShapes {
		testCases(shape, testOperands)
	}
	// Every operator, with the operands that matter: an integer operator,
	// the payload and a number.
	short := []string{"-eq", "a[$(@S@)]", "1"}
	for _, op := range testUnary {
		testCases(`[ `+op+` "%[1]s" ]`, short)
		testCases(`[ `+op+` "%[1]s" -a `+op+` "%[2]s" ]`, short)
	}
	for _, op := range testBinary {
		testCases(`[ "%[1]s" `+op+` "%[2]s" ]`, short)
		testCases(`[ "%[1]s" `+op+` x -o x `+op+` "%[2]s" ]`, short)
	}
	return out
}

// differentialCases are the cases written by hand in differential.jsonl plus
// the generated ones.
func differentialCases(t *testing.T) []corpusCase {
	t.Helper()
	cases := loadCorpus(t, "differential.jsonl")
	seen := map[string]bool{}
	for _, k := range cases {
		// A case names the sentinel with the mark or, when PATH is what
		// finds it, by its file name.
		if !strings.Contains(k.Sh, sentinelMark) && !strings.Contains(k.Sh, filepath.Base(sentinelPath)) {
			t.Fatalf("differential.jsonl: %q has no %s", k.Sh, sentinelMark)
		}
		if seen[k.Sh] {
			t.Fatalf("differential.jsonl: %q is repeated", k.Sh)
		}
		seen[k.Sh] = true
	}
	for _, sh := range generatedCases() {
		if !seen[sh] {
			seen[sh] = true
			cases = append(cases, corpusCase{Sh: sh})
		}
	}
	return cases
}

// oracle is the header of oracle.jsonl: the mksh that answered.
type oracleHeader struct {
	KSH string `json:"ksh"`
	SDK string `json:"sdk"`
}

// loadOracle reads testdata/oracle.jsonl: the header and, per case, whether
// the real mksh ran the sentinel.
func loadOracle(t *testing.T) (oracleHeader, map[string]bool) {
	t.Helper()
	type line struct {
		oracleHeader
		Sh  *string `json:"sh"`
		Ran bool    `json:"ran"`
	}
	var head oracleHeader
	ran := map[string]bool{}
	for i, l := range readJSONL[line](t, "oracle.jsonl") {
		if i == 0 {
			if l.Sh != nil || l.KSH == "" {
				t.Fatal("oracle.jsonl: the first line must be the header with the mksh version")
			}
			head = l.oracleHeader
			continue
		}
		if l.Sh == nil {
			t.Fatalf("oracle.jsonl: line %d has no case", i+1)
		}
		ran[*l.Sh] = l.Ran
	}
	return head, ran
}

// Spec M2.5 §2.1, criteria 3 and 4: every case is recorded against a real
// mksh, and whatever ran the sentinel there is 🔴 special here.
func TestWhatMkshRunsIsSpecial(t *testing.T) {
	c := mustNew(t, "")
	_, ran := loadOracle(t)
	cases := differentialCases(t)
	missing, gaps := 0, 0
	for _, k := range cases {
		did, recorded := ran[k.Sh]
		if !recorded {
			if missing++; missing <= 10 {
				t.Errorf("%q is not in oracle.jsonl: record it (see host/README.md)", k.Sh)
			}
			continue
		}
		if !did {
			continue
		}
		if r := c.Classify(sh(withSentinel(k.Sh))); r.Level != Red || !r.Special {
			if knownM2Gaps[k.Sh] {
				gaps++
				continue
			}
			t.Errorf("mksh runs the sentinel in %q and the classifier says %v special=%v (%s)", k.Sh, r.Level, r.Special, r.Primary.Rule)
		}
	}
	if gaps != len(knownM2Gaps) {
		t.Errorf("%d of the %d known gaps of M2 are open: delete the closed ones from knownM2Gaps", gaps, len(knownM2Gaps))
	}
	if missing > 10 {
		t.Errorf("…and %d more cases are not in oracle.jsonl", missing-10)
	}
	if len(ran) != len(cases)-missing {
		t.Errorf("oracle.jsonl has %d cases and the corpus %d: record it again", len(ran), len(cases))
	}
}

// Spec M2.5 §5.3: a payload that never fires proves nothing. Each form of
// payload, and each carrier, runs the sentinel in at least one recorded case.
func TestEveryPayloadFiresSomewhere(t *testing.T) {
	_, ran := loadOracle(t)
	fires := func(match func(sh string) bool) bool {
		for sh, did := range ran {
			if did && match(sh) {
				return true
			}
		}
		return false
	}
	for name, p := range payloads {
		for _, carrier := range carriers {
			prefix := fmt.Sprintf(carrier[:strings.LastIndex(carrier, "%s")], p)
			if !fires(func(sh string) bool { return strings.HasPrefix(sh, prefix) }) {
				t.Errorf("payload %s never runs the sentinel through %q", name, carrier)
			}
		}
	}
}

// TestRecordOracle runs every differential case on the mksh of an Android
// emulator and rewrites testdata/oracle.jsonl and testdata/mksh-builtins.tsv.
// It needs ADBUDDY_MKSH_SERIAL and ADBUDDY_MKSH_ADB (scripts/emulator.sh
// start prints them) and refuses anything that is not an emulator.
func TestRecordOracle(t *testing.T) {
	serial, adbPath := os.Getenv("ADBUDDY_MKSH_SERIAL"), os.Getenv("ADBUDDY_MKSH_ADB")
	if serial == "" || adbPath == "" {
		t.Skip("set ADBUDDY_MKSH_SERIAL and ADBUDDY_MKSH_ADB to record (scripts/emulator.sh start)")
	}
	if !strings.HasPrefix(serial, "emulator-") {
		t.Fatalf("ADBUDDY_MKSH_SERIAL=%q is not an emulator: the cases never run on a real phone", serial)
	}
	adb := func(args ...string) string {
		t.Helper()
		cmd := exec.Command(adbPath, append([]string{"-s", serial}, args...)...)
		var stderr bytes.Buffer
		cmd.Stderr = &stderr
		out, err := cmd.Output()
		if err != nil {
			t.Fatalf("adb %q: %v\n%s", args, err, stderr.String())
		}
		return strings.ReplaceAll(string(out), "\r\n", "\n")
	}
	cases := differentialCases(t)
	local := filepath.Join(t.TempDir(), "m25-diff")
	if err := os.Mkdir(local, 0o755); err != nil {
		t.Fatal(err)
	}
	write := func(name, content string) {
		t.Helper()
		if err := os.WriteFile(filepath.Join(local, name), []byte(content), 0o644); err != nil {
			t.Fatal(err)
		}
	}
	for i, k := range cases {
		write(strconv.Itoa(i), withSentinel(k.Sh))
	}
	write("sentinel", "#!/system/bin/sh\n: >"+sentinelRan+"\n")
	// Each case runs the way adb runs a command: sh -c with the text, in
	// its own process, with no input and a time limit. The sentinel is put
	// back before each one: a case may overwrite it (echo x >"$v"). A case
	// that leaves something in the background gets a second to fire, and
	// one that hits the time limit counts as having run the sentinel: what
	// it would have done next is not known. Each case runs in a session of
	// its own, and whatever it leaves alive is killed before the next one
	// (watch would go on running the sentinel): the session first, then
	// the processes of the shell user that lost their parent.
	write("run.sh", `n=$1
i=0
orphans() {
	ps -u shell -o PID,PPID | while read -r pid ppid; do
		[ "$ppid" = 1 ] && echo "$pid"
	done
}
base=" $(orphans | tr '\n' ' ') "
while [ $i -lt $n ]; do
	rm -rf `+sentinelRan+` `+diffCwd+` `+sentinelPath+`
	cp `+diffDir+`/sentinel `+sentinelPath+`
	chmod 755 `+sentinelPath+`
	mkdir `+diffCwd+`
	cd `+diffCwd+`
	text=$(cat `+diffDir+`/$i)
	setsid -w /system/bin/sh -c 'echo $$ >`+diffDir+`/sid; exec timeout 5 /system/bin/sh -c "$0"' "$text" </dev/null >/dev/null 2>&1
	code=$?
	case $text in *' & '*|*' &') sleep 1;; esac
	if [ -e `+sentinelRan+` ]; then
		echo "ran $i"
	elif [ $code -eq 124 ] || [ $code -eq 137 ] || [ $code -eq 143 ]; then
		echo "ran $i"
	fi
	pkill -9 -s "$(cat `+diffDir+`/sid)" 2>/dev/null
	for pid in $(orphans); do
		case $base in *" $pid "*) ;; *) kill -9 "$pid" 2>/dev/null ;; esac
	done
	i=$((i+1))
done
echo "done $n"
`)
	clean := "rm -rf " + diffDir + " " + diffCwd + " " + sentinelPath + " " + sentinelRan + " " + diffWords
	adb("shell", clean)
	defer adb("shell", clean)
	// Only the shell matters here. On the Android 17 image surfaceflinger
	// crashes every few seconds (Assertion failed:
	// !rcEnc->featureInfo()->hasReadColorBufferDma) and Android restarts
	// its framework over and over: cases slow down until they hit the time
	// limit, and that would count as running the sentinel. So the framework
	// is stopped while the cases run (root: the image is userdebug) and
	// started again afterwards.
	adb("shell", "su 0 stop")
	defer adb("shell", "su 0 start")
	adb("push", local, diffDir)
	out := adb("shell", "sh "+diffDir+"/run.sh "+strconv.Itoa(len(cases)))
	if !strings.Contains(out, "done "+strconv.Itoa(len(cases))) {
		t.Fatalf("the run did not finish:\n%s", out)
	}
	ran := map[int]bool{}
	for _, line := range strings.Split(out, "\n") {
		if rest, ok := strings.CutPrefix(line, "ran "); ok {
			i, err := strconv.Atoi(strings.TrimSpace(rest))
			if err != nil {
				t.Fatalf("bad line %q", line)
			}
			ran[i] = true
		}
	}
	if len(ran) == 0 {
		t.Fatal("no case ran the sentinel: the sentinel does not work")
	}

	head := oracleHeader{
		KSH: strings.TrimSpace(adb("shell", `echo "$KSH_VERSION"`)),
		SDK: strings.TrimSpace(adb("shell", "getprop ro.build.version.sdk")),
	}
	type row struct {
		Sh  string `json:"sh"`
		Ran bool   `json:"ran"`
	}
	rows := make([]row, len(cases))
	for i, k := range cases {
		rows[i] = row{Sh: k.Sh, Ran: ran[i]}
	}
	sort.Slice(rows, func(i, j int) bool { return rows[i].Sh < rows[j].Sh })
	var b bytes.Buffer
	enc := json.NewEncoder(&b)
	enc.SetEscapeHTML(false)
	if err := enc.Encode(head); err != nil {
		t.Fatal(err)
	}
	for _, r := range rows {
		if err := enc.Encode(r); err != nil {
			t.Fatal(err)
		}
	}
	if err := os.WriteFile(filepath.Join("testdata", "oracle.jsonl"), b.Bytes(), 0o644); err != nil {
		t.Fatal(err)
	}

	// The builtins: every lower-case word in the shell's binary, asked to
	// whence -v, plus the predefined aliases.
	bin := filepath.Join(t.TempDir(), "sh")
	adb("pull", "/system/bin/sh", bin)
	data, err := os.ReadFile(bin)
	if err != nil {
		t.Fatal(err)
	}
	words := map[string]bool{".": true, ":": true, "[": true}
	for _, w := range regexp.MustCompile(`[a-z][a-z_]{0,15}`).FindAll(data, -1) {
		words[string(w)] = true
	}
	list := make([]string, 0, len(words))
	for w := range words {
		list = append(list, w)
	}
	sort.Strings(list)
	wordsFile := filepath.Join(t.TempDir(), "m25-words")
	if err := os.WriteFile(wordsFile, []byte(strings.Join(list, "\n")+"\n"), 0o644); err != nil {
		t.Fatal(err)
	}
	adb("push", wordsFile, diffWords)
	kinds := map[string]string{}
	for _, line := range strings.Split(adb("shell", `while read -r w; do whence -v "$w"; done <`+diffWords+` 2>&1; true`), "\n") {
		name, rest, ok := strings.Cut(line, " is a")
		if !ok {
			continue
		}
		switch {
		case strings.Contains(rest, "special shell builtin"):
			kinds[name] = "special builtin"
		case strings.Contains(rest, "shell builtin"):
			kinds[name] = "builtin"
		case strings.Contains(rest, "reserved word"):
			kinds[name] = "reserved"
		case strings.HasPrefix(rest, "n alias for"):
			kinds[name] = "alias"
		}
	}
	names := make([]string, 0, len(kinds))
	for name := range kinds {
		names = append(names, name)
	}
	sort.Strings(names)
	var tsv strings.Builder
	tsv.WriteString("# Builtins, reserved words and predefined aliases of " + head.KSH + " (whence -v). Written by TestRecordOracle.\n")
	for _, name := range names {
		tsv.WriteString(name + "\t" + kinds[name] + "\n")
	}
	if err := os.WriteFile(filepath.Join("testdata", "mksh-builtins.tsv"), []byte(tsv.String()), 0o644); err != nil {
		t.Fatal(err)
	}
	t.Logf("%d cases, %d ran the sentinel, %d builtins; %s", len(cases), len(ran), len(names), head.KSH)
}
````

	"strings"

// maxDepth limits `sh -c` / `su -c` nesting.
const maxDepth = 8

// Android's /system/bin/sh is mksh, so the parser uses the MirBSD Korn dialect.
func newParser() *syntax.Parser {
	return syntax.NewParser(syntax.Variant(syntax.LangMirBSDKorn))
}

// scope is what the analysis of one script carries into the shells it
// starts (sh -c, su -c, find -exec sh -c…). Nothing else crosses: a script
// never exports a variable (see vars.go), so a nested shell starts from the
// phone's own environment.
type scope struct {
	depth int
}

func (s scope) child() scope { return scope{depth: s.depth + 1} }

// evaluator classifies one script. It only understands the shell it lists:
// every other statement, word part, expansion, builtin or variable name is
// 🔴 special (spec M2.5 §4). What mksh does with each admitted form is
// recorded against a real mksh in testdata/oracle.jsonl.
type evaluator struct {
	c        *Classifier
	sc       scope
	numeric  map[string]bool // variables proven to hold a number (see numericVars)
	unproven map[string]bool // variables the script sets that are not
	out      []Finding
}

var textUnsupported = Text{
	EN: "Run shell code ADBuddy does not analyse: {cmd}",
	ES: "Ejecutar código de shell que ADBuddy no analiza: {cmd}",
}

// unsupported records shell the evaluator does not list.
func (e *evaluator) unsupported(reason string, n syntax.Node) {
	e.out = append(e.out, unanalysable("shell.unsupported", reason, []string{nodeText(n)}, textUnsupported))
}

// classifyScript parses a shell command line and classifies every simple
// command in it, including those inside $(…), pipelines, lists, subshells,
// loops and here-documents.
func (c *Classifier) classifyScript(src string, sc scope) []Finding {
	if sc.depth > maxDepth {
		return []Finding{unanalysable("shell.depth", "too many nested shells", []string{src}, textParse)}
	}
	file, err := newParser().Parse(strings.NewReader(src), "")
	if err != nil {
		return []Finding{unanalysable("shell.parse", "cannot parse: "+err.Error(), []string{src}, textParse)}
	}
	e := &evaluator{c: c, sc: sc}
	e.numeric, e.unproven = numericVars(file)
	e.stmts(file.Stmts)
	return e.out
}

func (e *evaluator) stmts(list []*syntax.Stmt) {
	for _, s := range list {
		e.stmt(s)
	}
}

func (e *evaluator) stmt(s *syntax.Stmt) {
	// `cmd &` (at the end or in the middle) and mksh's `cmd |&`.
	if s.Background || s.Coprocess || s.Disown {
		e.out = append(e.out, backgroundFinding("runs in the background", []string{nodeText(s)}))
	}
	for _, r := range s.Redirs {
		e.redirect(r)
	}
	switch cmd := s.Cmd.(type) {
	case nil: // only redirections
	case *syntax.CallExpr:
		e.call(cmd)
	case *syntax.BinaryCmd:
		switch cmd.Op {
		case syntax.AndStmt, syntax.OrStmt, syntax.Pipe:
			e.stmt(cmd.X)
			e.stmt(cmd.Y)
		default:
			e.unsupported("shell operator "+cmd.Op.String(), s)
		}
	case *syntax.IfClause:
		for c := cmd; c != nil; c = c.Else {
			e.stmts(c.Cond)
			e.stmts(c.Then)
		}
	case *syntax.WhileClause:
		e.stmts(cmd.Cond)
		e.stmts(cmd.Do)
	case *syntax.ForClause:
		e.forClause(cmd, s)
	case *syntax.Subshell:
		e.stmts(cmd.Stmts)
	case *syntax.Block:
		e.stmts(cmd.Stmts)
	case *syntax.TimeClause:
		if cmd.PosixFormat {
			e.unsupported("time with options", s)
		} else if cmd.Stmt != nil {
			e.stmt(cmd.Stmt)
		}
	default:
		// case, select, functions, [[ ]], (( )), let, typeset and the other
		// declarations, and whatever the parser learns next.
		e.unsupported("shell construct", s)
	}
}

// forClause admits `for name in words; do …; done` with a name of the
// script's own (see ownName).
func (e *evaluator) forClause(f *syntax.ForClause, s *syntax.Stmt) {
	wi, ok := f.Loop.(*syntax.WordIter)
	if !ok || f.Select || !wi.InPos.IsValid() {
		// select, a C-style loop, or `for x; do`, which reads the positional
		// parameters.
		e.unsupported("shell construct", s)
		return
	}
	if !ownName(wi.Name.Value) {
		e.out = append(e.out, nameFinding(wi.Name.Value))
	}
	for _, w := range wi.Items {
		e.word(w)
	}
	e.stmts(f.Do)
}

// call classifies a simple command: its assignments and its words.
func (e *evaluator) call(ce *syntax.CallExpr) {
	if len(ce.Args) == 0 {
		for _, a := range ce.Assigns {
			e.assign(a)
		}
		return
	}
	for _, a := range ce.Assigns {
		e.envAssign(a)
	}
	ws := make([]Word, len(ce.Args))
	for i, w := range ce.Args {
		ws[i] = e.word(w)
	}
	e.out = append(e.out, e.c.evalWords(ws, e)...)
}

// redirect admits output to /dev/null, duplicates between numbered
// descriptors, input and here-documents. Output to any other file is a plain
// write: 🔴, not special.
func (e *evaluator) redirect(r *syntax.Redirect) {
	if r.N != nil && !isDigits(r.N.Value) {
		e.unsupported("redirection of a named descriptor", r)
		return
	}
	switch r.Op {
	case syntax.RdrOut, syntax.AppOut, syntax.RdrClob, syntax.AppClob, syntax.RdrInOut,
		syntax.RdrAll, syntax.RdrAllClob, syntax.AppAll, syntax.AppAllClob:
		w := e.word(r.Word)
		if !w.Dynamic && w.Value == "/dev/null" {
			return
		}
		e.out = append(e.out, redFinding("shell.redirect", "writes to "+w.Value, []string{r.Op.String(), w.Value}, textRedirect))
	case syntax.DplOut, syntax.DplIn:
		w := e.word(r.Word)
		if !w.Dynamic && (w.Value == "-" || isDigits(w.Value)) {
			return
		}
		e.out = append(e.out, redFinding("shell.redirect", "writes to "+w.Value, []string{r.Op.String(), w.Value}, textRedirect))
	case syntax.RdrIn, syntax.WordHdoc:
		e.word(r.Word)
	case syntax.Hdoc, syntax.DashHdoc:
		// The body expands like text in double quotes (with a quoted
		// delimiter it is one literal).
		if r.Hdoc != nil {
			e.parts(r.Hdoc.Parts, true)
		}
	default:
		e.unsupported("redirection "+r.Op.String(), r)
	}
}

func isDigits(s string) bool {
	if s == "" {
		return false
	}
	for _, r := range s {
		if r < '0' || r > '9' {
			return false
		}
	}
	return true
}

// nodeText prints a syntax node on one line, for titles.
func nodeText(n syntax.Node) string {
	// The printer prints expressions only inside their command or word.
	switch x := n.(type) {
	case *syntax.BinaryArithm, *syntax.UnaryArithm, *syntax.ParenArithm:
		n = &syntax.Word{Parts: []syntax.WordPart{&syntax.ArithmExp{X: x.(syntax.ArithmExpr)}}}
	case *syntax.Redirect:
		n = &syntax.Stmt{Redirs: []*syntax.Redirect{x}}
	case *syntax.ParamExp, *syntax.CmdSubst, *syntax.ArithmExp, *syntax.ProcSubst, *syntax.ExtGlob, *syntax.SglQuoted, *syntax.DblQuoted:
		n = &syntax.Word{Parts: []syntax.WordPart{x.(syntax.WordPart)}}
	}
	var b strings.Builder
	if syntax.NewPrinter(syntax.SingleLine(true)).Print(&b, n) != nil || b.Len() == 0 {
		return "…"
	}
	return b.String()
}

package classify

import (
	"regexp"
	"strings"

// word checks the parts of a word against the forms the evaluator admits
// and returns its value (see wordOf). Inside it, $(…) is classified as a
// script of its own and $((…)) must only see numbers.
func (e *evaluator) word(w *syntax.Word) Word {
	e.parts(w.Parts, false)
	return wordOf(w)
}

func (e *evaluator) parts(parts []syntax.WordPart, quoted bool) {
	for _, part := range parts {
		switch p := part.(type) {
		case *syntax.Lit:
		case *syntax.SglQuoted:
			// Text; $'…' is text with escapes, only known on the phone. Inside
			// double quotes or a here-document the parser only reads quotes
			// in the word of ${x:-…}, and there mksh takes them as text and
			// expands what they hold: echo "${x:-'$(reboot)'}" runs reboot.
			if quoted {
				e.unsupported("quotes inside an expansion in double quotes", p)
			}
		case *syntax.DblQuoted:
			if quoted {
				e.unsupported("quotes inside an expansion in double quotes", p)
				continue
			}
			e.parts(p.Parts, true)
		case *syntax.ParamExp:
			e.param(p, quoted)
		case *syntax.CmdSubst:
			if p.TempFile || p.ReplyVar {
				e.unsupported("mksh ${ …;} substitution", p)
				continue
			}
			e.stmts(p.Stmts)
		case *syntax.ArithmExp:
			if !arithOK(p, e.numeric) {
				e.out = append(e.out, arithFinding(nodeText(p)))
			}
		default:
			// <(…), extended globs and whatever the parser learns next.
			e.unsupported("shell expansion", part)
		}
	}
}

// paramOps are the ${x…} operators that only cut or replace the value of x
// as text.
var paramOps = map[syntax.ParExpOperator]bool{
	syntax.RemSmallPrefix: true, syntax.RemLargePrefix: true,
	syntax.RemSmallSuffix: true, syntax.RemLargeSuffix: true,
	syntax.DefaultUnset: true, syntax.DefaultUnsetOrNull: true,
}

// param admits $x, ${x}, $?, $#, ${#x} and ${x#p}, ${x##p}, ${x%p}, ${x%%p},
// ${x-p}, ${x:-p}. Reading a variable as a word does not evaluate its value
// again; the forms that assign (${x:=p}), evaluate arithmetic (${x:a:b},
// ${a[i]}) or name another variable (${!x}) are not admitted. quoted says
// the expansion is in double quotes or in a here-document (see parts).
func (e *evaluator) param(p *syntax.ParamExp, quoted bool) {
	if p.Param == nil || p.Excl || p.Width || p.Flags != nil || p.NestedParam != nil || p.Index != nil ||
		len(p.Modifiers) > 0 || p.Slice != nil || p.Repl != nil || p.Names != 0 {
		e.unsupported("parameter expansion", p)
		return
	}
	name := p.Param.Value
	if !nameRE.MatchString(name) && !(name == "?" || name == "#") {
		// $1, $@, $*, $$, $!, $-…
		e.unsupported("parameter $"+name, p)
		return
	}
	if p.Exp == nil {
		return
	}
	if !paramOps[p.Exp.Op] {
		e.unsupported("parameter expansion ${"+name+p.Exp.Op.String()+"…}", p)
		return
	}
	if p.Exp.Word != nil {
		e.parts(p.Exp.Word.Parts, quoted)
	}
}

var nameRE = regexp.MustCompile(`^[A-Za-z_][A-Za-z0-9_]*$`)

// wordOf computes the literal value of a word. Anything whose value is only
// known when the phone's shell runs it — expansions, substitutions, globs,
// braces, a leading ~ or $'…' — makes the word Dynamic. Braces and glob
// classes may span quoted parts: in {5,'reboot'} the parser sees "{5,",
// 'reboot' and "}", and the phone still expands it into two words.
func wordOf(w *syntax.Word) Word {
	// A word that is exactly [ ] { or } is a command name or a plain literal,
	// not a brace expansion or glob class: keep it static so `[ … ]` stays a
	// recognised command.
	if len(w.Parts) == 1 {
		if lit, ok := w.Parts[0].(*syntax.Lit); ok {
			switch lit.Value {
			case "[", "]", "{", "}":
				return Word{Value: lit.Value, node: w}
			}
		}
	}
	var b strings.Builder
	var st globState
	dyn := false
	for i, part := range w.Parts {
		switch p := part.(type) {
		case *syntax.Lit:
			v, d := unescapeUnquoted(p.Value, i == 0, &st)
			b.WriteString(v)
			dyn = dyn || d
		case *syntax.SglQuoted:
			if p.Dollar {
				dyn = true
			}
			b.WriteString(p.Value)
		case *syntax.DblQuoted:
			if p.Dollar {
				dyn = true
			}
			for _, q := range p.Parts {
				if l, ok := q.(*syntax.Lit); ok {
					b.WriteString(unescapeDouble(l.Value))
				} else {
					dyn = true
				}
			}
		default:
			dyn = true
		}
	}
	return Word{Value: b.String(), Dynamic: dyn, node: w}
}

// globState carries, across the parts of a word, whether an unquoted { or [
// has opened a brace expansion or a glob class.
type globState struct{ brace, bracket bool }

// unescapeUnquoted removes backslashes from an unquoted literal. It reports
// Dynamic for globs, a leading ~, an unquoted { or [ (which may open a brace
// expansion or a glob class), and a } or ] that closes one seen earlier in
// this literal or in an earlier literal of the same word (escaped closers
// count too, which only errs on the safe side).
func unescapeUnquoted(s string, first bool, st *globState) (string, bool) {
	var b strings.Builder
	dyn := false
	for i := 0; i < len(s); i++ {
		ch := s[i]
		if (ch == '}' && st.brace) || (ch == ']' && st.bracket) {
			dyn = true // brace expansion or glob class
		}
		switch {
		case ch == '\\' && i+1 < len(s):
			i++
			if (s[i] == '}' && st.brace) || (s[i] == ']' && st.bracket) {
				dyn = true
			}
			if s[i] != '\n' {
				b.WriteByte(s[i])
			}
			continue
		case ch == '*' || ch == '?':
			dyn = true
		case ch == '[':
			// An unquoted [ or { may open a glob class or a brace expansion,
			// whether or not a closer follows: treat the word as dynamic.
			st.bracket = true
			dyn = true
		case ch == '{':
			st.brace = true
			dyn = true
		case ch == '~' && i == 0 && first:
			dyn = true
		}
		b.WriteByte(ch)
	}
	return b.String(), dyn
}

func unescapeDouble(s string) string {
	var b strings.Builder
	for i := 0; i < len(s); i++ {
		if s[i] == '\\' && i+1 < len(s) {
			switch s[i+1] {
			case '$', '`', '"', '\\':
				b.WriteByte(s[i+1])
				i++
				continue
			case '\n':
				i++
				continue
			}
		}
		b.WriteByte(s[i])
	}
	return b.String()
}

package classify

import (
	"regexp"

	"mvdan.cc/sh/v3/syntax"
)

// A script only sets variables of its own: lower-case names. Every variable
// mksh or the phone's programs treat in a special way (PS4, ENV, IFS, PATH,
// LD_PRELOAD, the integer ones such as SECONDS…) is upper-case, so none of
// them has to be listed: `typeset +` and `env` in adb's shell show no
// lower-case name (recorded in testdata/oracle.jsonl). A script never
// exports one either, so no program and no nested shell sees them.

var ownNameRE = regexp.MustCompile(`^[a-z][a-z0-9_]*$`)

// ownName reports a variable name a script may assign.
func ownName(name string) bool { return ownNameRE.MatchString(name) }

// nameFinding is for an assignment, in any form, to a name that is not the
// script's own.
func nameFinding(name string) Finding {
	return unanalysable("shell.assign", "sets "+name+", a variable that is not the script's own (lower-case names only)", []string{name}, textAssign)
}

// commandEnv are the only variables a command may get in its environment
// (NAME=value command, env NAME=value command): they pick a language or a
// time zone. Anything else could change which program or library runs.
var commandEnv = map[string]bool{
	"LANG": true, "LC_ALL": true, "LC_COLLATE": true, "LC_CTYPE": true,
	"LC_MESSAGES": true, "LC_NUMERIC": true, "LC_TIME": true, "TZ": true,
}

// assign checks `name=word` as a statement of its own.
func (e *evaluator) assign(a *syntax.Assign) {
	if a.Name == nil || a.Index != nil || a.Array != nil || a.Append || a.Naked {
		// a[i]=…, a=(…), a+=… and whatever else the parser reads here.
		e.unsupported("assignment to an array or with +=", a)
		return
	}
	if !ownName(a.Name.Value) {
		e.out = append(e.out, nameFinding(a.Name.Value))
	}
	if a.Value != nil {
		e.word(a.Value)
	}
}

// envAssign checks `NAME=value command`.
func (e *evaluator) envAssign(a *syntax.Assign) {
	if a.Name == nil || a.Index != nil || a.Array != nil || a.Append || a.Naked {
		e.unsupported("assignment to an array or with +=", a)
		return
	}
	var v Word
	if a.Value != nil {
		v = e.word(a.Value)
	}
	if !commandEnv[a.Name.Value] || v.Dynamic {
		e.out = append(e.out, unanalysable("shell.assign", "sets "+a.Name.Value+" in the environment of a command", []string{a.Name.Value}, textAssign))
	}
}

// numericVars returns the variables of a script proven to hold a number:
// every assignment to them, anywhere in the script and whatever the order,
// is a number literal or admitted arithmetic. mksh evaluates the value of a
// variable used in arithmetic as an expression, $(…) included, so one
// assignment that is anything else (a word only known on the phone, read, a
// loop over words that are not numbers) makes the variable not numeric.
// unproven are the variables the script sets that are not numeric.
func numericVars(f *syntax.File) (numeric, unproven map[string]bool) {
	type assigned struct {
		values []*syntax.Word
		other  bool // set by read or by a loop over something that is not a number
	}
	vars := map[string]*assigned{}
	get := func(name string) *assigned {
		v := vars[name]
		if v == nil {
			v = &assigned{}
			vars[name] = v
		}
		return v
	}
	syntax.Walk(f, func(n syntax.Node) bool {
		switch n := n.(type) {
		case *syntax.Assign:
			if n.Name == nil {
				break
			}
			v := get(n.Name.Value)
			if n.Index != nil || n.Array != nil || n.Append || n.Value == nil {
				v.other = true
				break
			}
			v.values = append(v.values, n.Value)
		case *syntax.WordIter:
			v := get(n.Name.Value)
			if !n.InPos.IsValid() {
				v.other = true
			}
			for _, w := range n.Items {
				if lit := wordOf(w); lit.Dynamic || !numberRE.MatchString(lit.Value) {
					v.other = true
				}
			}
		case *syntax.CallExpr:
			// read NAME…, alone or behind a wrapper (command read x): every
			// static word of the command may be a name.
			var static []string
			reads := false
			for _, w := range n.Args {
				if lit := wordOf(w); !lit.Dynamic {
					static = append(static, lit.Value)
					reads = reads || lit.Value == "read"
				}
			}
			if reads {
				for _, name := range static {
					get(name).other = true
				}
			}
		}
		return true
	})
	// The largest set in which every assignment of every variable is a
	// number: start from all of them and drop until nothing changes
	// (i=$((i+1)) is a number as long as i is).
	numeric = map[string]bool{}
	for name, v := range vars {
		if !v.other && ownName(name) {
			numeric[name] = true
		}
	}
	for changed := true; changed; {
		changed = false
		for name := range numeric {
			for _, w := range vars[name].values {
				if !numericValue(w, numeric) {
					delete(numeric, name)
					changed = true
					break
				}
			}
		}
	}
	unproven = map[string]bool{}
	for name := range vars {
		if !numeric[name] {
			unproven[name] = true
		}
	}
	return numeric, unproven
}

// numericValue reports an assigned value that is a number literal or only
// one admitted arithmetic expansion.
func numericValue(w *syntax.Word, numeric map[string]bool) bool {
	if lit := wordOf(w); !lit.Dynamic {
		return numberRE.MatchString(lit.Value)
	}
	if len(w.Parts) != 1 {
		return false
	}
	a, ok := w.Parts[0].(*syntax.ArithmExp)
	return ok && arithOK(a, numeric)
}

package classify

import (
	"regexp"

	"mvdan.cc/sh/v3/syntax"
)

// mksh evaluates arithmetic in $((…)) and in the integer operands of test
// and [. A variable used there is not read as a number: its value is
// evaluated again as an expression, and an array index in that expression is
// expanded in full, $(…) included, so x='a[$(reboot)]'; echo $((x)) runs
// reboot. The evaluator only admits operands it can prove to be numbers
// (see numericVars); the other places where mksh evaluates arithmetic
// ((( )), let, [[ ]], ${x:a:b}, array indexes, typeset -i) are not admitted
// at all.

var numberRE = regexp.MustCompile(`^[+-]?([0-9]+|0[xX][0-9A-Fa-f]+|[0-9]+#[0-9A-Za-z]+)$`)

var textArith = Text{
	EN: "Evaluate shell arithmetic on a value that could hide code: {cmd}",
	ES: "Evaluar aritmética de la shell con un valor que podría esconder código: {cmd}",
}

func arithFinding(what string) Finding {
	return unanalysable("shell.script", "arithmetic on a value not proven to be a number", []string{what}, textArith)
}

// arithOK reports an arithmetic expansion that can only see numbers.
func arithOK(a *syntax.ArithmExp, numeric map[string]bool) bool {
	return !a.Bracket && !a.Unsigned && arithExprOK(a.X, numeric)
}

// arithExprOK admits number literals, parentheses, operators that assign
// nothing, variables proven numeric, $? and $#.
func arithExprOK(x syntax.ArithmExpr, numeric map[string]bool) bool {
	switch x := x.(type) {
	case *syntax.BinaryArithm:
		return !isArithAssign(x.Op) && arithExprOK(x.X, numeric) && arithExprOK(x.Y, numeric)
	case *syntax.UnaryArithm:
		return x.Op != syntax.Inc && x.Op != syntax.Dec && arithExprOK(x.X, numeric)
	case *syntax.ParenArithm:
		return arithExprOK(x.X, numeric)
	case *syntax.Word:
		if len(x.Parts) != 1 {
			return false
		}
		switch p := x.Parts[0].(type) {
		case *syntax.Lit:
			return numberRE.MatchString(p.Value) || numeric[p.Value]
		case *syntax.ParamExp:
			return numericParam(p, numeric)
		}
	}
	return false
}

// isArithAssign reports the assignment operators inside arithmetic (=, +=, …).
func isArithAssign(op syntax.BinAritOperator) bool {
	switch op {
	case syntax.Assgn, syntax.AddAssgn, syntax.SubAssgn, syntax.MulAssgn, syntax.QuoAssgn,
		syntax.RemAssgn, syntax.AndAssgn, syntax.OrAssgn, syntax.XorAssgn, syntax.ShlAssgn,
		syntax.ShrAssgn, syntax.AndBoolAssgn, syntax.OrBoolAssgn, syntax.XorBoolAssgn, syntax.PowAssgn:
		return true
	}
	return false
}

// simpleParam is $x or ${x}: no operator, index or modifier.
func simpleParam(p *syntax.ParamExp) bool {
	return p.Param != nil && !p.Excl && !p.Length && !p.Width && p.Flags == nil && p.NestedParam == nil &&
		p.Index == nil && len(p.Modifiers) == 0 && p.Slice == nil && p.Repl == nil && p.Names == 0 && p.Exp == nil
}

// numericParam is $x or ${x} of a variable proven numeric, $? or $#.
func numericParam(p *syntax.ParamExp, numeric map[string]bool) bool {
	return simpleParam(p) && (numeric[p.Param.Value] || p.Param.Value == "?" || p.Param.Value == "#")
}

// The words of test and [ (mksh's builtin), as the evaluator reads them.
const (
	testLiteral = iota // a static word
	testNumber         // only known on the phone, proven to be a number
	testData           // only known on the phone, in double quotes: one word
	testUnread         // anything else: it may split into operators
)

// testKind classifies one word of test or [.
func testKind(w Word, numeric map[string]bool) int {
	if !w.Dynamic {
		return testLiteral
	}
	if w.node == nil || len(w.node.Parts) != 1 {
		return testUnread
	}
	part := w.node.Parts[0]
	quoted := false
	if dq, ok := part.(*syntax.DblQuoted); ok {
		if dq.Dollar {
			return testUnread
		}
		quoted = true
		if len(dq.Parts) == 1 {
			part = dq.Parts[0]
		}
	}
	switch p := part.(type) {
	case *syntax.ParamExp:
		if numericParam(p, numeric) {
			return testNumber
		}
	case *syntax.ArithmExp:
		if arithOK(p, numeric) {
			return testNumber
		}
	}
	if quoted {
		return testData
	}
	return testUnread
}

var (
	testIntOps = map[string]bool{"-eq": true, "-ne": true, "-lt": true, "-le": true, "-gt": true, "-ge": true}
	// testUnaryOps are the unary file and string operators. -o (a shell
	// option) and -v (a variable, whose array index mksh would evaluate) are
	// left out on purpose.
	testUnaryOps = map[string]bool{
		"-b": true, "-c": true, "-d": true, "-e": true, "-f": true, "-g": true, "-G": true, "-h": true, "-k": true,
		"-L": true, "-n": true, "-O": true, "-p": true, "-r": true, "-s": true, "-S": true, "-t": true, "-u": true,
		"-w": true, "-x": true, "-z": true,
	}
	testBinaryOps = map[string]bool{"=": true, "==": true, "!=": true, "-nt": true, "-ot": true, "-ef": true}
	identRE       = regexp.MustCompile(`[A-Za-z_][A-Za-z0-9_]*`)
)

// testFindings checks the words of test or [ against a closed grammar, in
// which every operator is a static word:
//
//	expr    := term { (-a | -o) term }
//	term    := [ ! ] primary
//	primary := ( expr ) | UNARY word | word BINARY word | number INT number | word
//
// A word is static, a number, or data in double quotes. On the phone a word
// of data may itself be -eq or another integer operator, and mksh then
// evaluates its neighbours as arithmetic: a static neighbour such as -n
// reads the variable n. So a word of data with a word on each side needs
// neighbours that cannot reach a variable the script sets to something that
// is not a number (see inert).
func (e *evaluator) testFindings(ws []Word) []Finding {
	bad := func(why string) []Finding {
		return []Finding{unanalysable("shell.script", why, values(ws), textArith)}
	}
	args := ws[1:]
	if ws[0].Value == "[" {
		if len(args) == 0 || args[len(args)-1].Dynamic || args[len(args)-1].Value != "]" {
			return bad("[ without a closing ]")
		}
		args = args[:len(args)-1]
	}
	kinds := make([]int, len(args))
	for i, w := range args {
		kinds[i] = testKind(w, e.numeric)
		if kinds[i] == testUnread {
			return bad("a word of test that may split into operators on the phone")
		}
		if kinds[i] == testLiteral && (w.Value == "-v" || w.Value == "-o" && !testJoins(args, i)) {
			return bad("test " + w.Value + " reads a shell variable or option")
		}
	}
	p := &testParser{args: args, kinds: kinds}
	if !p.expr() || p.pos != len(args) {
		return bad("a test expression ADBuddy cannot read")
	}
	for i := range args {
		if kinds[i] != testData || i == 0 || i == len(args)-1 {
			continue
		}
		for _, j := range []int{i - 1, i + 1} {
			if !e.inert(args[j], kinds[j]) {
				return bad("a word of test only known on the phone could be an integer operator")
			}
		}
	}
	return nil
}

// testJoins reports whether the static -o at i joins two terms (there is a
// word on each side), as opposed to the unary -o OPTION.
func testJoins(args []Word, i int) bool {
	return i > 0 && i < len(args)-1
}

// inert reports a word mksh can evaluate as arithmetic without running
// anything: a number, or a static word that names no variable the script
// sets to something that is not a number.
func (e *evaluator) inert(w Word, kind int) bool {
	switch kind {
	case testNumber:
		return true
	case testLiteral:
		for _, name := range identRE.FindAllString(w.Value, -1) {
			if e.unproven[name] {
				return false
			}
		}
		return true
	}
	return false
}

// testParser reads the words of test with the grammar of testFindings.
type testParser struct {
	args  []Word
	kinds []int
	pos   int
}

func (p *testParser) lit(v string) bool {
	return p.pos < len(p.args) && p.kinds[p.pos] == testLiteral && p.args[p.pos].Value == v
}

func (p *testParser) litIn(set map[string]bool) bool {
	return p.pos < len(p.args) && p.kinds[p.pos] == testLiteral && set[p.args[p.pos].Value]
}

func (p *testParser) expr() bool {
	if !p.term() {
		return false
	}
	for p.lit("-a") || p.lit("-o") {
		p.pos++
		if !p.term() {
			return false
		}
	}
	return true
}

func (p *testParser) term() bool {
	if p.lit("!") {
		p.pos++
	}
	return p.primary()
}

func (p *testParser) primary() bool {
	switch {
	case p.pos >= len(p.args):
		return false
	case p.lit("("):
		p.pos++
		if !p.expr() || !p.lit(")") {
			return false
		}
		p.pos++
		return true
	case p.litIn(testUnaryOps) && p.pos+1 < len(p.args) && !p.binaryAt(p.pos+1):
		p.pos += 2
		return true
	case p.binaryAt(p.pos + 1):
		op := p.args[p.pos+1].Value
		if p.pos+2 >= len(p.args) {
			return false
		}
		if testIntOps[op] && !(p.number(p.pos) && p.number(p.pos+2)) {
			return false
		}
		p.pos += 3
		return true
	}
	p.pos++ // a word alone: true if it is not empty
	return true
}

// binaryAt reports a static binary operator at i.
func (p *testParser) binaryAt(i int) bool {
	return i < len(p.args) && p.kinds[i] == testLiteral && (testBinaryOps[p.args[i].Value] || testIntOps[p.args[i].Value])
}

// number reports a number literal or a word proven to be a number.
func (p *testParser) number(i int) bool {
	return p.kinds[i] == testNumber || (p.kinds[i] == testLiteral && numberRE.MatchString(p.args[i].Value))
}

// command may go on to its rule.
func (e *evaluator) builtin(ws []Word) []Finding {
	name := ws[0].Value
	vals := values(ws)
	if name == "[" || name == "test" {
		return e.testFindings(ws)
	}
	if grammar, ok := admittedBuiltins[name]; ok {
		if grammar == nil {
			return nil
		}
		if why := grammar(e, ws); why != "" {
			return []Finding{unanalysable("shell.builtin", why, vals, textUnsupported)}
		}
		return nil
	}
	if otherBuiltins[name] {
		return []Finding{unanalysable("shell.builtin", name+" is a shell builtin ADBuddy does not analyse", vals, textUnsupported)}
	}
	return nil
}

// readGrammar is `read [-r] name…`, with names of the script's own. Without
// a name read sets REPLY.
func readGrammar(_ *evaluator, ws []Word) string {
	args := ws[1:]
	if len(args) > 0 && !args[0].Dynamic && args[0].Value == "-r" {
		args = args[1:]
	}
	if len(args) == 0 {
		return "read without a variable name"
	}
	for _, a := range args {
		if a.Dynamic || !ownName(a.Value) {
			return "read into a variable that is not the script's own (lower-case names only)"
		}
	}
	return ""
}

// countGrammar is exit, break and continue: no argument, a number or $?.
func countGrammar(e *evaluator, ws []Word) string {
	switch {
	case len(ws) == 1:
		return ""
	case len(ws) == 2 && !ws[1].Dynamic && isDigits(ws[1].Value):
		return ""
	case len(ws) == 2 && testKind(ws[1], e.numeric) == testNumber:
		return ""
	}
	return ws[0].Value + " with an argument that is not a number"
}

// printfGrammar refuses -v, which stores the output in a shell variable, and
// an option only known on the phone, which may be -v. On the phone printf is
// a program, not a builtin; a build of mksh with its own printf would take it.
func printfGrammar(_ *evaluator, ws []Word) string {
	// Only the options before the format count: the first word that is
	// not one ends them.
	for _, a := range ws[1:] {
		if a.Dynamic || !strings.HasPrefix(a.Value, "-") || a.Value == "--" {
			break
		}
		if a.Value == "-v" {
			return "printf -v writes to a shell variable"
		}
	}
	return ""
}

// staticGrammar takes only static words.
func staticGrammar(_ *evaluator, ws []Word) string {
	for _, a := range ws[1:] {
		if a.Dynamic {
			return ws[0].Value + " with an argument only known on the phone"
		}
	}
	return ""
}

// change how the shell reports errors and traces, not what a word means.
var (
	setLetters = "efuvxC"
	setNames   = map[string]bool{
		"errexit": true, "noglob": true, "nounset": true, "verbose": true, "xtrace": true,
		"noclobber": true, "pipefail": true,
	}
)

// setGrammar is `set` with those options only: no positional parameters, no
// -A (an array) and nothing that changes how words expand.
func setGrammar(_ *evaluator, ws []Word) string {
	for i := 1; i < len(ws); i++ {
		a := ws[i]
		if a.Dynamic || len(a.Value) < 2 || (a.Value[0] != '-' && a.Value[0] != '+') {
			return "set with positional parameters or an argument only known on the phone"
		}
		flags := a.Value[1:]
		if flags == "o" {
			if i+1 >= len(ws) || ws[i+1].Dynamic || !setNames[ws[i+1].Value] {
				return "set -o with an option ADBuddy does not admit"
			}
			i++
			continue
		}
		if strings.Trim(flags, setLetters) != "" {
			return "set " + a.Value + " is not an option ADBuddy admits"
		}
	}
	return ""
}
